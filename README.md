# Indicadores-macro

Este projeto é um dashboard interativo construído com **Shiny** e **shinydashboard**, que visualiza em tempo real 10 indicadores econômicos brasileiros obtidos diretamente da API do Banco Central. 

## Indicadores incluídos

- IPCA mensal (%)
- IPCA acumulado 12 meses (%)
- SELIC meta ao ano (%)
- SELIC acumulada no ano (%)
- IBC-Br (proxy do PIB mensal)
- PIB trimestral (%)
- Inadimplência de Pessoa Física (%)
- Crédito Pessoa Física (R$ milhões)
- Dívida Bruta do Governo Geral (% do PIB)
- Índice de Commodities Brasil (IC-Br)
